# Data availability

**The code and the derived data products are published. The raw Space-Track
data is not redistributed.**

## Published, in this repository

| What | Where | Licence |
| --- | --- | --- |
| All code: ingestion, transformation, analysis, figures | this repository | MIT |
| Every figure and results table in the analysis | [`analysis/figures/`](analysis/figures/), with `SHA256SUMS` | MIT |
| Hardware-generation labels for 12,440 Starlink satellites | [`transform/seeds/starlink_generation_map.csv`](transform/seeds/starlink_generation_map.csv) | derived from GCAT, CC-BY |
| The schema of every table, and its tests | the published dbt docs, built from an empty warehouse ([ADR-0007](docs/adr/0007-publish-schema-and-aggregates-never-element-data.md)) | MIT |

The figures and tables are aggregates: per generation, altitude shell, storm
and month. No element set, and no row about a single satellite, is published.

## Not redistributed: Space-Track element sets

The orbital element sets every result is computed from are obtained from
[Space-Track.org](https://www.space-track.org), operated for the US Space
Force, under a user agreement that does not permit redistribution. They are
never committed: `data/` is gitignored, CI fails if anything under it is
tracked, and a pre-commit hook refuses such a commit.

**To reproduce them**, register for a free Space-Track account and run the
pipeline, which respects Space-Track's rate limits by construction:

```bash
uv run starlink-drag backfill --start 2020-01-01
make build                                      # or the two commands it runs
uv run python -m analysis.make_figures --check  # compare with the published figures
```

The analysis period is fixed at 2020-01-01 to 2026-09-16 in
`analysis/models/data.py`, and the figures are regenerated byte for byte from
a given warehouse ([ADR-0015](docs/adr/0015-analysis-outputs-are-pinned-committed-and-byte-reproducible.md)).
A warehouse rebuilt on a later day can still differ slightly: Space-Track
publishes corrected element sets for past epochs, and those corrections are
not frozen. `--check` says which outputs differ.

## Open sources

- **NASA OMNI** hourly space weather (F10.7, Kp, ap, Dst), retrieved through the
  NASA SPDF HAPI server: public domain. The analysis uses only OMNI for space
  weather.
- **GCAT**, Jonathan McDowell's General Catalog of Artificial Space Objects:
  CC-BY. The source of the generation labels.
- **NOAA SWPC** real-time products: public domain. Used only by the optional
  live nowcast (Phase 6), never by the analysis.

How to cite the work and its sources: [`CITATION.cff`](CITATION.cff).
